# Changelog

## v2.0.0 - June 2026

### New Features
- Rest Timer with keyboard shortcuts (Space/R/Esc)
- Progress Photos (front/side/back upload)
- Workout Calendar with color-coded days
- Exercise Database (50+ exercises with search/filter)
- Bengali/English language toggle for diet plans
- Toast notification system
- CSV export for workouts and progress

### Security Fixes
- Removed hardcoded JWT secret fallback
- Restricted CORS to frontend domain only
- Added password reset flow with crypto tokens

### UI Improvements
- ErrorBoundary for crash recovery
- Loading skeleton components
- Empty state illustrations
- Page transition animations
- Custom scrollbar styling
- Focus-visible and reduced motion support
- Accessibility improvements (aria labels)

### Developer Improvements
- Custom React hooks (useDebounce, useLocalStorage, useKeyPress)
- Utility helpers (date formatting, number formatting, validation)
- Reusable components (StatCard, ConfirmDialog, EmptyStates)

## v1.0.0 - May 2026

### Initial Release
- Workout Tracker with exercise logging
- AI Workout Generator (Gemini AI)
- Body Progress Tracking with charts
- Nutrition Tracker with calorie/macro tracking
- AI Fitness Coach chat
- Bangladeshi Diet Plans (6 workout days)
- Muscle Balance Analyzer
- Analytics Dashboard
- Gamification (XP, levels, badges)
- Dark glassmorphism UI
- Mobile responsive design
